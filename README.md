## About the Game

Built with Three.js, Block Math turns elementary math review into a wave-based browser game. Players respond to questions during monster encounters, and correct answers help them eliminate enemies and move through 100 sequential stages.

Four difficulty selections provide different question pools based on elementary-level curriculum topics. The longer progression features a boss every tenth stage, along with token earnings, a shop, power-ups, weapon appearances, and a character album saved locally by the browser.

## Core Features

- Defeat monsters by solving math questions during survival waves
- Advance through 100 stages, including a boss encounter at every 10th stage
- Choose from four modes, each with its own question set
- Practice material drawn from elementary-grade curriculum content
- Earn tokens and spend them in the in-game shop
- Use power-ups and collect alternate weapon skins
- Preserve character album progress in browser storage
- Play with keyboard controls or touch input on desktop and mobile browsers
- Launch directly from `index.html` without a compilation or build process
